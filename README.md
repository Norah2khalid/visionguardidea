# VISIONGUARD

منصة تفتيش صناعي للمنشآت النفطية والغازية. الواجهة عربية واتجاهها من اليمين إلى اليسار، وتفتح مباشرة على لوحة التحكم في وضع المحاكاة بدون تسجيل دخول.

## ما يعمل الآن

- أربعة أقسام: لوحة التحكم، المهام ومواقع التفتيش، التقارير، سجل التفتيش.
- خريطة متابعة محاكاة، تصوير تجريبي، تحليل تجريبي، ومراجعة بشرية.
- دورة المهمة من الإنشاء حتى التقرير والسجل، دون استبدال التفتيشات السابقة.
- تبديل أدوار العرض: المدير، المفتش، جامع التقارير. هذا التبديل واجهة فقط وليس صلاحية أمنية.
- البيانات التجريبية تُحفظ في المتصفح. لا توجد قراءات درون أو حساسات حية.

## قاعدة البيانات

مخطط PostgreSQL/Supabase في `supabase/migrations/20261005140000_visionguard.sql`.

- المعرّفات UUID.
- العلاقات والفهارس وحقول الوقت موجودة.
- RLS مفعّل. الزائر غير المسجّل لا يقرأ الجداول.
- الملفات في مساحات تخزين خاصة: صور التفتيش، الفيديو، مرفقات التقارير، والوثائق.
- مفتاح الخدمة لا يوضع في متغيرات `VITE_`.

وضع المحاكاة لا يتصل بقاعدة البيانات حتى لو وُجدت قيم Supabase في البيئة. الربط الإنتاجي يبقى طبقة لاحقة فوق نفس المخطط، مع Supabase Auth.

## الذكاء الاصطناعي

`src/services/ai` يعرّف واجهة مزود. التنفيذ الحالي `mock` ويَسِم كل نتيجة بـ «تحليل تجريبي». الواجهة لا تستورد مزودًا بعينه إلا عبر `getAiService()`.
